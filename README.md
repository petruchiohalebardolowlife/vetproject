# Сайт-визитка ветеринара — Кирилл Сачков

Статический сайт (одна главная страница с разделами + страница 404): React + TypeScript + Vite. Версия 2 — обновлённый дизайн (см. PROMPT.md); в PROMPT_V3.md — расширенный дизайн с анимациями. Серверной логики нет.

## Запуск

```bash
npm install
npm run dev      # режим разработки
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
npm run lint
```

## Что и где менять

| Что | Где |
|---|---|
| Пункты меню (якоря разделов), имя, описание, фото врача, пункты меню, текст футера | `src/data/content.ts` |
| Ссылки и картинки соцсетей | `src/data/socials.ts` |
| Цвета, отступы, радиусы | CSS-переменные в `src/styles/global.css` (`:root`) |
| Тексты разделов «О враче», «Услуги», «Блог», «Сотрудничество» (сейчас заглушки) | `src/data/sections.ts` |
| Реальная отправка заявки | `src/utils/submitBooking.ts` (сейчас только `console.log`) |

**Фото врача:** `src/assets/doctor.webp` (4:5), подключено в `content.ts`. Для замены положите новый файл с тем же именем или поменяйте импорт.

**Картинки соцсетей:** `src/assets/socials/*.webp`, все 480×640 (3:4). Чтобы добавить или заменить — положите файл такого же размера, импортируйте в `socials.ts` и укажите в поле `image`.

## Деплой на Vercel

Framework Preset: **Vite**, Build Command: `npm run build`, Output Directory: `dist`.
Сборка — обычная статика. Неизвестные адреса обрабатываются на клиенте (страница 404), поэтому `vercel.json` переписывает все пути на `index.html`. На собственном сервере нужен такой же fallback (например, nginx: `try_files $uri /index.html;`).
